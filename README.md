This a document that seeks to aid in the migration process of a company as it decides to move its two tiered web application to AWS servers. It initially utilised on premises servers. However as the company is initiating
this migration its processes align with the CLOUD ADOPTION FRAMEWORK and even more importantly the WELL ARCHITERTED FRAMEWORK.
Firstly i identified the components that are to be considered, then i move on to identify likely issues and vulnerabilities.
Then using the well architectured framework i identity one strength as well as an area of improvement that the company can tackle. All 6 sections of the WELL ARHICTECTED FRAMEWORK are addressed and an AWS service is suggested for each section
Then the next portion is the CLOUD ADOPTION FRAMEWORK(CAF) . Which is useful for measuring how ready one is for migration onto the cloud. The companies readiness is assessed according to the CAF along with the enablers
that would aid in its readiness.
Finally i drew a propsed architecture that addresses likely issues and also aligns with WAF AND CAF best practices. I utilised clickup to draw the diagram
