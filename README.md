This document provides an evaluation to support a company that is planning to migrate its two-tier web application from on-premises infrastructure to Amazon Web Services (AWS). As the organization begins this transition, the migration strategy is guided by two key AWS frameworks: the Cloud Adoption Framework (CAF) and the AWS Well-Architected Framework (WAF).

The analysis begins by identifying the major components of the existing workload. These components are examined to understand how the current system operates and to highlight potential risks, weaknesses, and vulnerabilities that may affect reliability, security, and scalability.

Next, the system is evaluated using the AWS Well-Architected Framework. For each of the five pillars of the framework, a current strength of the system is identified along with a recommended improvement. Each recommendation is supported by relevant AWS services that could help the organization implement best practices and improve the architecture during migration.

Following this, the organization’s readiness for cloud adoption is assessed using the AWS Cloud Adoption Framework (CAF). The assessment examines the company’s preparedness across the CAF perspectives and identifies key enablers that would support a successful migration to the cloud environment.

Finally, a proposed AWS architecture is presented that addresses the weaknesses identified in the existing system while aligning with both WAF and CAF best practices. The architecture demonstrates how the application can be redesigned to improve scalability, reliability, security, and operational efficiency in the AWS cloud environment.
